# SEC-2026-0117 — Node.js 20 (embargoed): exposure assessment

Status: **open, no fixed version available**. Written 2026-11-26.

## Advisory
The advisory is embargoed. Its details (affected component, CVE, affected ranges)
were not available to this assessment and could not be confirmed from public
sources. Nothing below should be read as a confirmed statement about Node 21/22+.
**Action for the owner:** once the embargo lifts, fill in the affected component and
ranges here and re-run the checks below.

## Are other majors unaffected?
Unknown. Node 21 is end-of-life (no security fixes), so it is not an acceptable
alternative whatever the advisory says. Even-numbered lines (22, 24) are the only
reasonable candidates; whether they are affected must be taken from the advisory
when published. Node 22 was **not** adopted in this change because that claim is
unverified, and a runtime bump would alter the p4 matrix (18, 20) semantics.

## Where Node 20 is used in this repo
- `p1-flaky.yml`, `p5-deploy.yml`: `node-version: 20`
- `p4-matrix.yml`: matrix `[18, 20]` (Node 18 is also EOL)
- No Dockerfile, no package.json, no dependencies; no production image.

## Risk in this repository
Low. All usage is on short-lived GitHub-hosted CI runners, running first-party
test scripts (`p1-flaky/test.js`, `p4-matrix/test.js`) and a smoke-test server
(`p5-deploy/server.js`) bound to localhost for ~2s and never exposed. No
untrusted input is parsed and no secrets are used by the Node steps. Until the
component is known, the exposure is limited to the CI runner lifetime.

## Compensating controls
- Keep workflows triggered only by repo-controlled paths; do not feed external/untrusted input to the Node steps.
- Keep the p5 server on localhost only; never publish it.
- No secrets in jobs that run Node (p3 secret is in a separate, non-Node workflow).
- Pin to the patched release as soon as one exists (update the three workflow files above).

## Follow-up
1. Watch the advisory for the fix; bump `node-version` in p1/p4/p5 and re-run all pipelines.
2. Consider dropping Node 18 from the p4 matrix (EOL, separate from this advisory).
